# Video Highlight Generator
Система автоматического создания видеохайлайтов с генерацией контента. Проект предназначен для обработки видеофайлов, выделения наиболее значимых моментов и создания текстового сопровождения.

## Функциональность
* Автоматическое выделение ключевых моментов в видео на основе аудиоанализа  
* Генерация текстовых постов для социальных сетей  
* Добавление профессиональных заголовков и интро/аутро  
* Пакетная обработка видеофайлов  
* Сохранение метаданных в JSON формате  

## Технологии
* Python 3.8+  
* Обработка видео: MoviePy  
* Анализ аудио: PyDub  
* Распознавание речи: Vosk (оффлайн)  
* Генерация текста: DeepSeek AI API  
* Обработка изображений: PIL (Pillow)  

## Установка и настройка
1. Установка зависимостей
```bash
pip install -r requirements.txt
```
2. Загрузка модели распознавания речи
Скачайте русскоязычную модель для Vosk и разместите в папке models/:
```bash
mkdir -p models
cd models
wget https://alphacephei.com/vosk/models/vosk-model-ru-0.42.zip
unzip vosk-model-ru-0.42.zip
```
3. Настройка API ключа
Создайте файл settings.py и укажите ваш API ключ DeepSeek:
```bash
DEEP_SEEK_API_KEY = "your_api_key_here"
DEEP_SEEK_BASE_URL = "https://api.deepseek.com/v1"
```
4. Отредактируйте основные параметры в основном скрипте:
```bash
input_video = "./media/test_videos/your_video.mp4"
output_video = "./media/result_videos"
```
5. Запуск обработки
```bash
python main.py
```

## Конфигурация
Основные настройки (settings.py)  
PROMPT - шаблон для генерации постов  
ADDING_INTRO - добавление интро/аутро  
FONT_TYPE, FONT_SIZE - параметры шрифта для заголовков  
TEMPERATURE - креативность генерации текста  
threshold - порог громкости для обнаружения сегментов  
min_segment_duration - минимальная длительность сегмента  
min_silence_duration - минимальная пауза между сегментами  

## Особенности работы
Процесс обработки
Аудиоэкстракция -> извлечение звуковой дорожки из видео ->  
-> Анализ громкости -> обнаружение наиболее значимых моментов ->  
-> Создание хайлайтов -> вырезка ключевых сегментов видео ->  
-> Распознавание речи -> преобразование аудио в текст ->  
-> Генерация поста -> создание текстового контента ->  
-> Добавление заголовков -> наложение текста на видео->  
-> Сохранение результатов -> экспорт видео и метаданных   

## Форматы поддержки
Видео: MP4, AVI, MOV, MKV  
Аудио: WAV (автоматическая конвертация)  
Метаданные: JSON
